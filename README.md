# DCT App

![DCT App](https://img.shields.io/badge/DCT-App-blue)

## Giriş

DCT App, kullanıcıların en son haberleri, trendleri ve önerileri takip edebileceği modern bir haber uygulamasıdır. Bu uygulama, kullanıcıların ilgi alanlarına göre kişiselleştirilmiş içerik sunar ve kullanıcı dostu bir arayüz ile kolayca kullanılabilir.

## Özellikler

- **Gündem**: En son haberler ve trendler hakkında bilgi edinin.
- **Teknoloji**: Teknoloji dünyasındaki en yeni gelişmeleri takip edin.
- **Oyun**: Oyun dünyasındaki en son haberleri ve incelemeleri keşfedin.
- **Spor**: Spor dünyasındaki en güncel haberleri alın.
- **Kişiselleştirilmiş İçerik**: İlgi alanlarınıza göre öneriler alın.
- **Karanlık Mod**: Göz yormayan karanlık mod seçeneği.

## Kendi Makinenizde Çalıştırmak için Kurulum Aşamaları

1. Bu projeyi klonlayın:
   ```bash
   git clone https://github.com/alparslanmaral/DCTapp.git
   ```
2. Proje dizinine gidin:
   ```bash
   cd DCTapp
   ```
3. Gerekli bağımlılıkları yükleyin:
   ```bash
   npm install
   ```

## Kullanım

1. Uygulamayı başlatın:
   ```bash
   npm start
   ```
2. Tarayıcınızda `http://localhost:3000` adresine gidin.
